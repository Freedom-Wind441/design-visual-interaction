# 滑块与数值输入

## 适用条件

拖动、范围/数值、步进、滚动冲突、配置保存或输入反馈存在问题。

## 目标与约束

表达范围、当前值、单位和生效方式。区分连续与离散选项，保持已有数值含义、范围及配置兼容。

## 依赖与联动

父级开关读设置模块；手势冲突读动效；预览、提交与持久化混乱时协作架构技能。拖动重绘不等同于保存。

## 实施

- 核对最小/最大、步长、单位、默认与有效值来源。映射往返一致、边界可达，显示取整不改变实际值，零不作缺省。
- 区分预览和提交，保留已有实时生效语义；昂贵操作可按项目规则合并，最终值不可丢失，取消含义明确。
- 可拖动区足够且不遮挡邻项，与父级横滑/纵滚协商归属，不拦截全部方向，不借用普通按钮逻辑。
- 使用平台原生或等价可访问语义，暴露名称、范围、值和单位，保留键盘/辅助调整；精确输入和非拖动替代按平台/项目要求提供。
- 父项禁用时保留数值并清楚表现不可调整；主题切换和重建不重置配置。

## 验收

检查两端、步进、零值、快速拖动、取消、滚动竞争、禁用恢复、重建重启和替代输入。显示、有效、提交与保存值一致，无高频重复副作用。
