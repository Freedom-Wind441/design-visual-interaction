# 颜色与材质

## 适用条件

主题漂移、动态色、自定义色、透明、模糊、对比或能力回退问题。

## 目标与约束

保持层级、操作辨识与可读性。材质符合产品与平台，不强迫透明，不把不同语义合为同一强调色。

## 依赖与联动

字形/字号读排版；已采用或明确请求液态玻璃才读风格模块；偏好、能力探测及回退协作架构技能。

## 实施

- 追踪背景、表面、前景、强调、危险、禁用、焦点的语义来源。区分动态色、自定义色与有效色，使用明确优先级，回退不覆盖选择。
- 检查明暗、饱和色、动态背景和透明叠加的真实组合，不只检查未合成色值；控件与焦点也需可辨识。
- 有 WCAG 目标的 Web 项目按当前等级测量文字及非文本对比，使用官方定义、阈值与例外。原生项目遵循平台要求，不照搬 Web 像素。
- 区分真实背景采样/模糊和渐变/截图近似；不能实现则明确替代效果。覆盖减少透明、API 不支持及性能受限时的可读回退。
- 分开内容和装饰；表面透明度不连带文字、图标或焦点变淡。可调参数有有效范围、实际作用与重置路径。

## 验收

检查实际合成、主题、代表背景、焦点/禁用/错误、回退和配置恢复。语义不反转，内容可读，不把近似当原生特效。
