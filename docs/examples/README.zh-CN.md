# 公开项目真实前后对照

[English](./README.md) · **简体中文**

以下三组案例全部来自公开仓库，按固定 commit 与父提交读取实际源码，回溯说明本 Skill 的模块应如何处理类似问题。它们不代表本 Skill 完成过这些历史修复，不是效果基准，也不要求项目换用这些组件库。没有私人项目源码。

| 案例 | 问题 → 最小处理 | 对应模块 | 本轮实际验证 |
| --- | --- | --- | --- |
| [React Aria 按压捕获](./press-capture.md) | 不检查捕获所有权便释放 → 在原路径前加条件 | 按钮、动效、验证 | 两版各4项JS替身契约，旧版1项失败，后版全过 |
| [Radix 重叠滑块](./slider-commit.md) | 两个thumb重叠后漏提交 → 比较完整数值数组 | 滑块、验证 | 两版各4项JS闭包契约，旧版1项失败，后版全过 |
| [Flutter导航字体](./navigation-theme.md) | 缺少组件级覆盖入口 → 沿用组件/主题/默认的优先级 | 导航、排版、基线 | 两版各3项静态优先级检查，没有执行Dart |

各案例文档（英文）均包含问题、源码根因、模块、最小改动、验证和剩余缺口，链接准确前后片段、上游commit及父版本。来源与片段指纹见[记录](./public-provenance.json)，许可见[第三方说明](./third-party-notices.md)。

```bash
node scripts/check_public_examples.cjs
```

前两组只执行提取的实际JS路径及明确替身；第三组只审查实际Dart表达式。预期旧版失败用于确认反例，不代表旧版通过。没有运行完整上游测试、真实浏览器、Flutter运行时或设备；审阅过上游新增测试，不等于本轮重跑上游测试通过。片段也不是完整修复移植包。

原有[按钮事件演练](../evaluation/results.md#1-mature-button-fixture)与[token演练](../evaluation/token-case/TASK.md)另标为合成场景。完整源码片段、第三方许可和仓库检查脚本不放入安装目录；技能内仅附带按需读取的原创案例摘要与上游链接。
